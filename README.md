# نظام الحضور الذكي بالتعرف على الوجوه
## Face Recognition Attendance System

نظام ويب متكامل للحضور يعتمد على التعرف على الوجوه باستخدام Python و Flask و OpenCV.

## المميزات
- ✅ تسجيل الأشخاص بالصور
- ✅ التعرف على الوجوه بالكاميرا المباشرة
- ✅ رفع الصور للتعرف
- ✅ سجلات الحضور اليومية
- ✅ تصدير CSV
- ✅ واجهة ويب عربية

## التشغيل السريع
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح: http://127.0.0.1:5000
